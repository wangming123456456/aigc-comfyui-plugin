# AIGC 画布 · ComfyUI 节点插件

给 [AIGC 画布](https://github.com/wangming123456456/aigc-studio)（Infinite Canvas）用的专属节点：在画布上选一个 ComfyUI 工作流，填提示词、挂参考图，点发送就把结果写回画布，外观和行为跟原生图片节点一致。

## 安装

插件市场 →「官方插件」里找 `ComfyUI 节点`，或「第三方插件」里填：

```
https://cdn.jsdelivr.net/gh/wangming123456456/aigc-comfyui-plugin@main/comfyui.js
```

装好后节点菜单里会多出「ComfyUI 节点」。

## 使用说明

### 1. 先把 ComfyUI 连上

1. 启动本机 ComfyUI，浏览器打开 `http://127.0.0.1:8188` 确认能用。
2. 画布打开「配置 → ComfyUI」：
   - **服务地址**：留空就是 `http://127.0.0.1:8188`；
   - **代理地址**：建议填 `http://127.0.0.1:23210`，并先把它跑起来：`npx @basketikun/canvas-proxy`。留空时插件会自动探测这个端口，探测到就用；
   - 点「测试连接」，提示版本号就说明通了。

> 为什么需要代理：ComfyUI 对带 `Origin` 头的请求直接回 403，浏览器直连必被挡。代理会去掉 `Origin` 并自己应答预检。

### 2. 把工作流导进「工作流库」

在 ComfyUI 里用 **「工作流 → 导出 → 导出 API」** 存成 json（普通 `.json` 是节点图格式，跑不了，插件会提示重新导出）。

回到「配置 → ComfyUI」的「工作流库」：

- 点「导入 JSON 文件」选文件，或直接拖文件到粘贴区，按文件名自动入库；
- 也可以手动粘贴 JSON 再点「保存工作流」；
- 库条目只在配置页维护，画布节点只从下拉里选。

### 3. （可选）挑几个参数上卡片

同一页最下方「卡片上显示的参数」：

- 只列出**会真正执行**的节点（从输出节点回溯能走到的）；
- 每个节点展开后是该节点可改的参数，勾选后才会出现在画布的参数卡上；一个都不勾表示全部显示；
- 右侧控件可直接改工作流默认值：有候选值的（模型、采样器、调度器…）是下拉，布尔值是「是/否」，其余是输入框；改完自动存回工作流库；
- 工作流引用的模型在这台 ComfyUI 上不存在时，对应下拉会标红。

### 4. 在画布上使用节点

从节点菜单新建「ComfyUI 节点」，空态显示「空图片节点」，点开下方面板：

- **参考图行**：上游连线的图片自动排第一（高亮描边，点 × 可临时忽略）；点 `+` 从画布挑图，排在后面、可单独移除；按顺序填给工作流里的 `LoadImage`，数量超了会标红提示。右侧「反推」按钮见下一节。
- **提示词**：左栏正向、右栏反向。左栏留空时自动用上游文本节点的内容。
- **⚙ 参数**：调当前工作流参数（只显示配置页勾过的那些），改哪项覆盖哪项。
- **底栏**：左边尺寸/步数摘要，中间选工作流，右边发送（运行中变成停止）。

发送后结果写回本节点，可以继续连下游节点取用。

### 5. 反推提示词

面板右上「反推」：拿第一张参考图（没选就用上游图）交给画布配置的**文本模型**写一段提示词，成功直接填进正向栏。

- 要求文本模型支持看图（Gemini 2.x、GPT-4o 这类），不支持会在按钮旁报错；
- 会覆盖正向栏现有内容，想保留先复制出去。

### 6. 运行时你会看到什么

- 生成中：节点里显示「生成中… 12s」并每秒递增；
- 成功：显示结果图，状态变「完成」；
- 失败：节点显示「运行失败」+ 原因，悬停看完整报错；
- **执行前预检**：提交前核对工作流用到的 checkpoint / LoRA / VAE / UNET / CLIP / ControlNet / 放大模型和输入图片是否存在，缺了直接报文件名，不会排进队列。

### 常见问题

| 现象 | 原因 / 处理 |
| --- | --- |
| 测试连接失败 | ComfyUI 没启动、端口不对，或没配代理导致 403 |
| 提交时 403 | 没走代理。跑起 `canvas-proxy`，配置页填 `http://127.0.0.1:23210` |
| 「缺少文件：xxx」 | 这台 ComfyUI 的 `models/` 或 `input/` 里没有该文件，装好或在下拉里重选 |
| 参数卡太大 | 配置页只勾几个参数；卡片随画布缩放，放大后被裁掉时平移画布 |
| 改了工作流库没生效 | 面板打开时才读库，切走节点再点回来即可；运行前也会重新读 |
| 库里条目被删了 | 节点回退用自己缓存的那份工作流，仍可运行 |
| 反推报错 | 当前文本模型不支持看图，或渠道 Key 无效 |
| 更新后版本没变 | jsDelivr 对 `@main` 有缓存，等几小时或改用带版本的 tag 地址 |

## 自己构建

本插件依赖 AIGC 画布的插件 SDK（宿主仓库未公开），构建时用 `CANVAS_SDK` 指向它：

```bash
npm install
CANVAS_SDK=/path/to/infinite-canvas/plugins/canvas/sdk/src npm run build
```

产物是同目录的 `comfyui.js`，单个 ESM 文件，提交后即可被 jsDelivr 分发。
